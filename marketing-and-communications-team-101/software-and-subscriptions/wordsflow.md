# Wordsflow

Wordsflow is a plugin for InDesign that creates live links between Word documents and InDesign stories for seamless, on-going edits.

Wordsflow allows you to link a Word doc to your InDesign document, then sync changes between the InDesign document and Word doc without losing formatting changes. This is useful for copyediting proposals or corporate collateral in Word while allowing the designer to make progress in InDesign.&#x20;
